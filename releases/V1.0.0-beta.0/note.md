# Bond v1.0.0-beta.0

🚀 **First Public Beta Release**

Bond is an agentic coding IDE for Windows, built to understand your projects, work with your local files, and help you build software with AI.

### What's Included

- 🤖 Agentic coding
- 🧠 Project-aware intelligence
- 🛠️ Developer tools
- ⚡ Real-time agent activity
- 🔌 Multiple AI providers
- 💻 Windows x64 support

### Requirements

- Windows 10 / 11
- x64
- 4 GB RAM minimum
- 2 GB storage

> ⚠️ This is an early beta release. Bugs and unexpected behavior may occur.
