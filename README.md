# Bond

### Agentic Coding IDE for Windows

Bond is an AI coding agent that understands your projects, works with your local files, uses developer tools, and helps you build software with natural language.

## Features

- 🤖 Agentic coding
- 🧠 Project-aware intelligence
- 🛠️ File and terminal tools
- ⚡ Real-time agent activity
- 🔌 Multiple AI providers
- 💻 Windows focused
- 🔐 No account required

## Download

**[Download Bond for Windows](../../releases/latest)**

### Requirements

- Windows 10 / 11
- 64-bit (x64)
- 4 GB RAM minimum
- 2 GB available storage
